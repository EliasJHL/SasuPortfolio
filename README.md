# Sasu, comédien voix

Portfolio de Sasu : React, Vite, Tailwind, motion, React Bits et Magic UI.

```sh
npm install
npm run dev     # http://localhost:5173
npm run build   # site statique dans dist/
```

Tout le contenu (profil, démo, doublages, contacts) se modifie dans `src/contenu.ts`.
Les médias vont dans `public/media/`.
